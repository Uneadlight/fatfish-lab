# 读一个库的四步：选材、重写、差分、变异验证

## 复用：四步 + 模板

1. **选材**：500–800 行核心实现、最好有测试；npm 包通常只有 `dist/`，`curl -L` 必须（registry 会 302 到 CDN）。
2. **读**：先找「顺序约束」（什么必须在什么之后、用完要 delete/还原），再看它砍了什么；不要从函数名读起。
3. **重写**：用自己的话写一遍，砍掉的边角写进笔记，别宣称「完全等价」。
4. **验证**：差分测试（同一套用例跑两个实现，比行为不比结构）→ **变异验证**（故意改坏一处，必须精准挂掉对应那条）。
5. **沉淀**：写进这一页，回填候选路线库。

模板：`<工作区>\tools\learn\differential-template.mjs` —— 复制过去改 3 处（import、make、scenarios）。
三个高频坑写在模板注释里：场景对象每边新建、Blob/Promise 先归约再比、异步返回数组要先 await。

已读：hookable 6.1.2（257 行）、ofetch 1.5.1（349 行）、unstorage 2.0.0-beta.0（581 行）。

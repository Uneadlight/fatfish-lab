# 实验：让 3B 当「提交说明 vs 代码改动」的守门人（失败）

> **结论先行：这个任务放弃，微调也不做。** 下面记录的是"为什么我认为该停"，而不是"怎么把它做成"。

## 想解决什么

我每天提交十几次，有时会写出跟改动对不上的说明（写"修并发"、实际只改了注释）。想用一个本地 3B（`qwen2.5:3b`）在提交前拦一道：给它看提交说明 + diff，让它判"配不配"。

选这个任务的原因：**训练数据自动存在**——我自己 6 个仓库里 200 多条提交，正例（说明与改动一致）和反例（故意错配）都能造出来。

## 怎么做的

`make_samples.py`：从 206 条真实提交里造 **20 条样本**——

- **10 条诚实提交**（`label: consistent`）：说明与 diff 一致，包括"改了很多文件的"和"只改一行的"
- **10 条错配**（`label: suspect`）：把说明换成另一个仓库、另一类改动的说明
- 三档难度（easy / medium / hard），**每个仓库最多 2 条**保证多样性
- diff 截断到 6 个文件 / 每文件 12 行 / 3000 字符

防止一个隐蔽的坑：`git log --stat` 在中文件名下会输出 `\346\216` 这种八进制转义，必须加 `-c core.quotePath=false`。

## 三轮结果（指标在 `metrics.json`）

| 轮次 | 提示词 | 总准确率 | **诚实提交召回** | 错配召回 | **平衡准确率** |
|---|---|---|---|---|---|
| v1 | 简洁判据 + 两行输出 | 12/20 = 0.60 | **2/10 = 0.20** | 10/10 = 1.00 | **0.60** |
| v2 | 加基础率 + 强制先拆断言 | 2/20 = 0.10 | 0/10 | 2/10 | 0.10 |
| v3 | 修好参数（400 / 30 行 / 6000 字符） | 12/20 = 0.60 | **2/10 = 0.20** | 10/10 = 1.00 | **0.60** |

## 怎么读这三行

**① 0.60 不等于"六成准"。** 这个任务永远猜 `SUSPECT` 的基线就是 **0.50**（10 个错配全报、10 个诚实的全冤枉）。所以 0.60 意味着**有效能力只有 10 个百分点**，而且这点能力**全在"认出错配"上**——它认不出诚实提交。

**② v1 和 v3 提示词差很多、结果完全一致 → 不是提示词问题。** 两轮的提示词结构、判据、输出格式都不同，指标一模一样（连错的那 8 条都是同一批）。这说明撞的是**能力上限**，不是没调好。

**③ v2 的 0.10 是我自己的错，不是模型的错。** `num_predict=220` 太小，20 条里有 15 条写到"断言:"就被截断（平均输出只有 87 字符）；diff 也只给了 12 行/文件。**看到低分先怀疑自己的实验，不是先怀疑对象。**

## 为什么停

1. **它判的是"语义是否对应"，3B 没有这个能力。** 它认得出"文件路径完全不同"这种**硬错配**（10/10），认不出"文件对得上、内容也对得上"这种需要理解的情况（2/10）。
2. **微调救不了。** LoRA 只能教它"模仿格式"（输出格式、判据措辞），教不会它"判断这两段文字说的是不是同一件事"。而且 3B LoRA 需要 6–7 GB 显存，逼近本机 5732 MiB 的红线。
3. **不该为了"用上这个模型"去找任务。** 它能干的是另一件事（见下）。

## 它到底能干好什么

**长日志归因**（`../README.md` 里的 `triage.py`）：8/8 样本、精确率 0.94。区别在判据——

- 长日志里找错行：有 `ERROR` / `FAILED` / `MiB` / `assert` 这类**硬证据**可对，模型只负责"提名"，规则负责"验证据"
- 说明核对 diff：要的是**语义是否对应**，没有硬证据可以验

一句话边界：**它是形状识别器，不是语义判断器。**

## 复现

```bash
# 造样本（需要先 clone 那几个仓库，或改 REPOS 指向你自己的）
python make_samples.py

# 跑评测（需要本机 ollama + qwen2.5:3b）
python baseline.py
```

`metrics.json` 是三轮的汇总，原始逐条输出（每份 42 KB 的 `baseline-*-result.json`）没有带进来——**结论比原始记录更有用，而它们占地十倍**。
